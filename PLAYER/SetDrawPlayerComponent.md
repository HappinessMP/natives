# SET_DRAW_PLAYER_COMPONENT

## Declaration
```cpp
// 0x3EFE3DC8
void SET_DRAW_PLAYER_COMPONENT(int componentId, bool enable);
```

### Arguments
- **int:** componentId
- **bool:** enable

### Results

## Description
Hides (`false`) or shows (`true`) a component (see `SET_CHAR_COMPONENT_VARIATION`) on every character with a player model on this client: the main character and the multiplayer models, for all players at once.
