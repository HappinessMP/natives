# IS_POLICE_DISPATCH_REDUCED

## Declaration
```cpp
// 0x6E0A60AC
bool IS_POLICE_DISPATCH_REDUCED();
```

### Arguments

### Results
- **bool**

## Description
Returns `true` if the police uses the multiplayer numbers of the original game (default) and `false` if `SET_POLICE_DISPATCH_REDUCED` switched it to the singleplayer numbers.
