# GET_NUMBER_OF_CHAR_PROP_TEXTURE_VARIATIONS


### Arguments
- **int:** charIndex
- **int:** position
- **int:** propIndex

### Results

## Description
Returns how many textures the given prop at the given position has, 0 if the prop does not exist. See `SET_CHAR_PROP_INDEX` for the positions.
