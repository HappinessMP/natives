# GET_CHAR_TEXTURE_VARIATION

## Declaration
```cpp
// 0x3A7B78C5
int GET_CHAR_TEXTURE_VARIATION(int charIndex, int componentNumber);
```

### Arguments
- **int:** charIndex
- **int:** componentNumber

### Results
- **int**

## Description
Returns the texture the char wears for the given component, 0 is `a`. See `SET_CHAR_COMPONENT_VARIATION` for the component numbers.
