# SET_PED_WINDY_CLOTHING_SCALE

## Declaration
```cpp
// 0x12865550
void SET_PED_WINDY_CLOTHING_SCALE(int charIndex, float scale);
```

### Arguments
- **int:** charIndex
- **float:** scale

### Results

## Description
Sets how strongly the wind moves the clothes of the char, from 0.0 to 1.0. Values outside this range are limited to it.
