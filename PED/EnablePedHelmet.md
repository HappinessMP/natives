# ENABLE_PED_HELMET

## Declaration
```cpp
// 0xC704586
void ENABLE_PED_HELMET(Ped ped, boolean enable);
```

### Arguments
- **Ped:** ped
- **boolean:** enable

### Results

## Description
Allows (`true`) or forbids (`false`) the char to get a helmet, on a motorbike as well as through `GIVE_PED_HELMET`.
