# REMOVE_PED_HELMET

## Declaration
```cpp
// 0x15F033A6
void REMOVE_PED_HELMET(Ped ped, boolean instantly);
```

### Arguments
- **Ped:** ped
- **boolean:** instantly

### Results

## Description
Takes the helmet off the char. With `instantly` set to `true` it disappears right away, with `false` the char takes it off with an animation. A hat the helmet replaced comes back.
