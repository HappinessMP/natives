# SET_CHAR_PROP_INDEX_TEXTURE

## Declaration
```cpp
// 0x57390041
void SET_CHAR_PROP_INDEX_TEXTURE(Ped ped, int position, int propIndex, int textureIndex);
```

### Arguments
- **Ped:** ped
- **int:** position
- **int:** propIndex
- **int:** textureIndex

### Results

## Description
Puts a prop on the char at the given position with the given texture (0 is `a`). The texture is not checked, see `GET_NUMBER_OF_CHAR_PROP_TEXTURE_VARIATIONS`. See `SET_CHAR_PROP_INDEX` for the positions and the limits.
