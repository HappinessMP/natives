# SET_VOICE_ID_FROM_HEAD_COMPONENT

## Declaration
```cpp
// 0x2794E6B
void SET_VOICE_ID_FROM_HEAD_COMPONENT(int charIndex, int charComponent, bool male);
```

### Arguments
- **int:** charIndex
- **int:** charComponent
- **bool:** male

### Results

## Description
Gives a char with a multiplayer model (`M_Y_MULTIPLAYER`, `F_Y_MULTIPLAYER`) a voice that fits its head. Only `charIndex` is used, the other two arguments have no effect.
